One word for the whole internet.

## The word

> brainrot

Eight characters. It is funny by itself, true about the internet as a
whole, and not the first obvious word anyone reaches for. The internet
is an endless feed of low-effort content that melts attention — the word
names that condition in one beat, and a reader laughs, then nods.

## Run

```sh
node main.ts
```

Writes the word to `/output/entry.txt`. Deterministic: the word is a fixed
string, so every run writes identical bytes.
